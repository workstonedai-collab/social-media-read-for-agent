# 与 Agent Reach 的协作方向

2026-10-24：保留本项目作为国内四平台深度阅读的主要实现。Agent Reach 1.6.0 当前覆盖更广的互联网渠道，但没有本项目完整的微博、知乎、公众号读取与小红书逐图OCR、缺图补读链路。整体迁移会丢失已实现的取材能力并增加账号与浏览器迁移成本。

## 已落实的复用

- 适配 Reach 的按平台持久化限流冷却策略，原始 MIT 署名与许可单独保留。
- 用现有 SQLite、平台锁和任务引擎承接状态，不新增 Reach 运行依赖或复制其用户配置。
- 能力声明与最近动作证据分开；成功、部分结果、失败、缓存、演示与历史版本不能互相代替。
- Reach 上已有的可选协作说明沿用同一 PR 更新到 1.6 文档结构；上游是否接纳由维护者决定。它是文档协作，不代表自动路由已集成。

## 接下来的边界

本项目优先改善可回查片段、有限批量取材、真实样本OCR评测和跨平台等待。通用互联网渠道优先交给宿主已有工具或 Reach，不为平台数量重复实现。未来如有实际需求，再做显式选择的 CLI 适配；禁止在平台拒绝、验证或限流后自动换阅读器重试。

账号、浏览器资料和缓存分别管理。不自动将 Reach 的本机登录复制到本项目，也不将本项目历史内容或账号状态提交到上游。
