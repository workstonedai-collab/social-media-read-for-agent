# 三个可以直接复制的试用任务

先完成一个短任务，再扩大范围。以下数量是操作上限，实际结果以工具回执为准。来源不足时保留不足，不用模型补齐。

## 任务一 第一次读懂小红书图文

> 只用已经接通的小红书，搜索“个人知识管理工具”，最多3条。选择一篇适合阅读的图文笔记，读取配文及图片文字，再查看最多2条首层评论、每条最多1条回复。请列出实际搜索条数、正文读取状态、图片已处理和未读数量、评论范围及来源。最后用200字以内说明这条内容讲了什么。不要把OCR当成逐字准确，也不要把未读到评论写成没有评论。遇到平台验证或限流就停止。

完成标志：当前 Agent 真正调用了搜索和阅读工具，并解释结果覆盖；只有登录检查或搜索摘要不算完成。

## 任务二 开发产品前找需求线索

> 我在考虑开发个人知识管理工具。请使用已经接通的平台，优先小红书与知乎，每个平台最多搜索3条，合计最多阅读4篇原文。对适合的内容读取有限评论；公众号留言不支持，不要尝试。请区分用户经历、教程、品牌推广与作者观点，整理：反复出现的问题、具体使用场景、相反例子和下一步该向用户确认的问题。每项保留来源与原始日期；日期不明就写不明。说明实际覆盖和未验证之处，不推断市场份额或把少量样本说成普遍结论。

完成标志：每条主要判断有读过的内容作依据，样本类型明确，并给出值得后续访谈验证的问题。

## 任务三 读取一篇公众号文章并追问

> 请读取我接下来提供的公众号文章链接。先确认取得了正文，报告标题、原始日期、正文覆盖与来源。如果只有搜索摘要、页面打不开或正文不完整，请直接说明。读到正文后，整理作者主要论点、使用的例子，以及哪些是作者判断。然后等待我追问。不要尝试公众号留言，也不要把多年旧文当成当前市场动态。
