# 试用反馈卡片

可直接复制到原帖回复，也可提交 GitHub Issue。不需要提供账号、Cookie、密码、验证码、签名链接或完整日志。

1. 我从哪里看到项目：
2. 我的系统与 Agent（版本不知道可留空）：
3. 我想完成的任务：
4. 做到哪一步（还没安装 / 安装完成 / 已连接 / 已搜索 / 已读正文 / 完成调研）：
5. 卡住或需要自己折腾的地方、下次还想用来做什么：

选填：大约花了多久？需要人工协助几次？

只粘贴脱敏错误状态。例如“content_loading_timeout”，不粘贴浏览器资料、会话标识或真实调研全文。没有手机、未完成登录可写“等待本人登录”，这样能与代码故障分开处理。
