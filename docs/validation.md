## 已通过的本地验证

- Python 33 项检查通过：来源 URL 与参数边界、凭据脱敏、私有文件权限、缓存与模式隔离、部分成功、取消、有界超时、MCP 初始化与类型检查、写操作拒绝、HTTP 来源与令牌校验、公众号解析与验证页停止、公开文章提取、重定向限制、日期估计标签、正文失败语义。
- 官方 MCP TypeScript SDK 通过 stdio 完成七个工具的发现、四平台演示搜索与逐条阅读、有限评论和发布请求拒绝。
- 官方 MCP 客户端读取一条已取得的小红书真实缓存内容：live 模式、110 字符、cache.used=true。该检查证明接口返回真实模式的已存资料，不是一次新的平台访问，也不等于实际自然语言 Agent 使用验收。
- 实际本机 HTTP 服务验证：无令牌读取历史返回 403；外部 Origin 返回 403；发布请求返回 400；演示搜索返回任务并完成。
- 浏览器完成演示搜索、正文、评论、历史回查；未捕获控制台错误。真实模式界面用于公众号阅读测试并明确显示失败。
- 前端 JavaScript、Python 源码和两个 Mac 启动器的语法检查通过。尚未进行手机设备与新机器安装验收。

## 浏览器连接

用户明确授权后，创建独立 Chrome 资料 Social Read，保持未登录 Google。通过 OpenCLI README 的官方应用商店链接安装扩展 1.0.24；界面显示“OpenCLI 已添加到 Chrome”。OpenCLI 1.8.6 本机服务与扩展连接通过。项目将专用 context ID 保存在 Git 排除的私有状态中，真实模式不允许未指定资料的搜索与读取。

第一次账号检查报告三个平台均需登录。小红书正常登录后，身份接口能返回账号信息，但搜索页仍显示登录提示；用户完成该搜索页的正常登录后，原页面显示真实结果，项目搜索才取得五条。这说明身份接口返回成功不能替代搜索访问验收。
