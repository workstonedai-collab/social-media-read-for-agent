### 真实调研发现并修复的问题

1. 小红书搜索偶发空返回，旧任务仍显示 success。现等待有标题及访问参数的卡片，任一平台未返回资料时保留已完成项并标 partial 或 failed；不是证明平台没有相关内容。仍需跨主题、跨日期观察。
2. OpenCLI 的等待选择器在新页面尚无 body 时使用 MutationObserver(document.body)，已复现 TypeError。改用固定内部选择器和有界就绪轮询，覆盖笔记、评论与公众号；加载超时不再直接解释为删除。
3. 小红书评论在标题出现后尚未加载，曾返回0；增加有界内容等待。图片或表情评论保留未读标识，不静默丢掉；修正回复对象，深层树结构未验证时 depth=null。
4. 同一知乎文章两次早期读取为1762、2357字符；增加正文稳定等待后复测2357字符，仍不声称付费或平台不可见部分可读。
5. 微博与知乎早期评论请求超时；只读网络超时增加最多一次有界恢复，验证、访问拒绝和限流不反复尝试。后续相同微博及知乎文章评论均通过。
6. 错误分类的未限定数字429曾匹配日志中的进程编号，误报限流；现只匹配独立状态码，原误分类记录保留。
7. 图片 CDN 下载曾导致9图样本只读8张或6张。保留每张失败位置及 partial；使用正常来源 Referer、图片指纹及半小时明确缓存。最终 Codex 复测同一9图全部通过，不覆盖前面的失败。
8. 网页以前回看评论历史没有渲染评论；现可回看评论，历史显示文章标题和任务时间，逐图文字独立展开。
9. 长期驻留的 MCP 进程不会随代码自动热更新。当前对话曾继续调用旧代码；停止旧进程后连接不会在该对话自动恢复，出现 Transport closed。正式配置已恢复原名称，最终 Codex 验收使用重新启动的桌面随附客户端并通过。更新后应重连该服务或新开客户端会话，不重复提交平台请求。当前旧对话连接不作为最新版本已连接的证明。
