# 验证范围与已知限制

当前版本：**0.1.0a9 公开预览版**。本页说明已验证的用户路径和实际限制；离线演示、隔离安装、真实平台读取分别记录，不互相替代。

## a9 首次使用与当前会话

从公开安装包取得全新源码目录，下载项目独立运行时、安装本地组件与独立OCR，生成隔离Codex配置，不复制账号或Cookie。实际创建空白专用Chrome资料，由Agent在官方商店点击添加，用户确认最后的权限弹窗；新连接自动识别并保存，随后打开小红书登录页。

用户暂时没有手机，选择稍后登录。该步骤保留为login_pending，后续设置验收不再访问该平台，不能算作小红书首次登录通过。通过新安装实际生成的Codex配置另建标准MCP连接，确认七工具可发现，公众号搜索1条、刷新正文1181字符，非正文缓存。见[首次使用回执](a9-new-user.json)。这仍是在同一台Mac的新目录/新资料测试，不是全新操作系统测试。

当前Codex对话直接加载a9；小红书最终搜索路径的两次样本均返回1条，耗时约18.8、18.1秒，两次均使用一次空白页提前恢复。刷新阅读1104字符、9/9图片处理完成。评论首测出现content_ready超时；增加只在开始滚动/展开回复前允许的一次恢复后，重测取得2条首层、2条回复，该次重测未用到新增恢复。微博、知乎基本搜索各取得1条。见[当前Codex回执](a9-current-codex.json)。

空白导航底层问题仍可出现。a9把首个持续空白页的恢复起点提前至约4秒，恢复页保留完整等待预算，必要时唤起专用任务窗口；可读卡片仍有明确等待上限。有限样本不能证明长期稳定。最初失败和候选方案失败记录留在本机，不覆盖首次基线。

## 独立安装

本机 macOS Apple Silicon 从全新源码目录（路径含空格）开始，安装子进程的 PATH **没有 Python、Node 或 npm**。安装器按固定 SHA256 下载 Python3.11.17、Node22.23.3，安装项目本地 OpenCLI1.8.6，生成隔离 Codex/Hermes/通用配置，并实际通过七工具虚构数据搜索、四次阅读和有限评论。

验证了已有客户端设置保留、配置权限、第二次运行复用且changes为空、未采用未经确认的日常浏览器、未复制账号或历史状态。该检查证明运行环境和配置可自动准备，**不代表在新机器上完成了扩展授权与真实账号登录**。详细脱敏回执见 [独立安装](a8-portable-install.json)。

```sh
python3 scripts/verify_clean_install.py --portable --output .state/portable-install.json
```

项目持续集成在 macOS/Linux 运行行为检查、可重现演示、隔离配置与独立安装；实际结果以 [GitHub Actions](https://github.com/workstonedai-collab/social-media-read-for-agent/actions/workflows/verify.yml) 为准。CI没有社交账号，不执行平台登录。

独立Python上的RapidOCR安装、模型预热及空白图片no_text_detected检查也通过；不需要系统Swift工具链来使用该OCR路径。见 [可选OCR验收](a8-portable-ocr.json)。

## 已验证的失败处理

- 新页先确认目标导航，再短同步探测实际内容；探测和桥接共用剩余总预算，避免内层上限提前杀掉合法请求。
- 小红书首个页面持续空白约4秒提前进入一次独立页面恢复，保留navigation_not_started原因；恢复页保留完整导航预算。普通加载失败最多恢复一次，不是无限重试，不轮换账号或代理。
- 评论区迟于正文挂载时会等待；加载停滞或预算耗尽且未确认结尾时报告不完整，不把空数组当已读成功。
- 图片逐张保留检查点。真实九图样本曾缺1张，补读复用8张、只处理缺失1张，最终9/9；另一个十图样本10/10新处理完成。
- 公众号使用正常来源点击与正文区域读取，保留日期来源、段落、代码块和图片链接；失败报告具体阶段。
- 兼容读取代码可在同一MCP连接空闲时加载。入口、工具结构、客户端首次发现与依赖环境变动仍可能需要宿主刷新，不能保证永不重连。

## 尚未验证或未支持

新机器操作系统上的首次使用、小红书空白资料首次登录后的全流程、跨日期长期稳定性、Windows一键入口、Linux musl、完整评论树、全部图片/视频/语音和复杂公式准确性尚未验收或未提供。自动专用Chrome启动主要覆盖macOS；Linux桌面需Agent协助连接。公众号留言不支持。

反馈请提供平台、工具版本、明确状态和脱敏步骤。不要上传浏览器资料、密码、验证码、Cookie、账号身份、真实调研全文或带签名的私有链接。
