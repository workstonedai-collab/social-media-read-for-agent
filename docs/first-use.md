# 第一次使用智能体国内社媒使用工具

把项目交给已有的本地 Agent，由它准备环境；你在专用浏览器确认扩展权限，并在社交平台正常登录。先接通一个平台，完成一次搜索和阅读，再按需增加平台。

## 开始前

首批建议使用 macOS、Google Chrome，以及能够在本机执行安装和调用工具的 Codex 或 Hermes。请准备可以正常使用的社媒账号，建议选择个人隐私内容较少的专用账号。

你不需要预装 Python、Node、npm、Docker，不需要找浏览器资料编号或复制 Cookie。首次需要联网下载独立运行环境和组件；下载、识别模型与 Agent 自身运行可能需要等待。本项目不收取模型 API 费用，你的 Agent 仍按原有模型设置和计费方式运行。

Linux 的核心安装与离线检查已有覆盖，自动打开专用浏览器主要验证于 macOS。Windows 的一键流程尚未验收。只有网页聊天、不能执行本地任务的 Agent，不能直接使用这套本机读取工具。

## 第一步 把这段话交给你的 Agent

> 请安装并配置 https://github.com/workstonedai-collab/social-media-read-for-agent 。先阅读 AGENTS.md、README 和安装说明，自动检查并准备独立运行环境，只配置我当前使用的客户端，保留已有设置。先接通小红书，使用专用 Chrome 资料；已有专用连接就复用。需要我确认官方扩展权限或在平台页面登录时再引导我。不要索取 Cookie、密码或验证码。完成后用当前对话的工具实际搜索、阅读一篇图文笔记，并说明图中文字和评论读到了多少。

如果你想先用微博或知乎，把“小红书”换成对应平台。公众号使用公开文章与搜狗索引，不需要登录公众号后台。

## 第二步 等 Agent 准备环境

Agent 会取得项目、检查安装入口、下载并校验独立运行时，安装读取组件和可选的本机 OCR，再合并自己的工具配置。已有项目与客户端设置应保留，不需要你逐条复制命令。

没有 Git 的电脑，也可以由 Agent 取得项目 Release 中的源码压缩包。macOS 用户可以解压后双击“安装.command”，再回到 Agent 继续。系统若正常询问是否打开文件，请阅读提示后确认；不需要关闭系统安全保护。

看到“环境已就绪”还不代表平台已经能读，后面还要完成授权、登录和实际读取。

## 第三步 确认官方 Chrome 扩展权限

没有现成连接时，Agent 会打开空白专用 Chrome 资料和 OpenCLI 官方商店页面，继续操作“添加至 Chrome”。你阅读最终弹窗后决定是否添加。

OpenCLI 扩展权限较广，包括网站数据、页面调试、下载和标签页等，实际以 Chrome 提示为准。这个项目只开放登记的读取工具，但不会缩小扩展自身的权限。因此请使用专用浏览器资料，避免混入日常浏览的账号和内容。

如果 Agent 没有桌面操作能力，它应清楚说明需要你点击哪个按钮。确认后回到对话，告诉它“已添加扩展”，由它检查连接；不需要你查编号、导出 Cookie 或重装全部依赖。

## 第四步 在平台页面正常登录

Agent 打开你要用的平台，你直接扫码，或在平台自己的页面输入账号和密码。密码、验证码、Cookie 都不发到聊天里。遇到安全验证由本人正常完成。

暂时没有手机或不想登录，可以告诉 Agent“先保留进度，晚点继续”。它应保留待办，不再反复访问待登录平台；之后从这一步继续。

先登录一个平台即可。登录微博、知乎按同样方式处理；微信公众号不需要公众号运营后台权限。

## 第五步 完成第一个任务

> 在我已连接的小红书搜索“个人知识管理工具”，最多取3条。选一篇适合阅读的图文笔记，读取配文和图片文字，再查看最多2条首层评论、每条最多1条回复。请说明实际读了哪些内容、哪些图片未读、OCR是否可能有错字，并给我一段带来源的简短总结。只使用已经能访问的内容，遇到登录、验证码、限流或拒绝访问就停止该平台并说明原因。

阅读完成后，你应该看到：实际搜索条数；至少一篇原文的读取结果；图中文字的处理范围或明确失败原因；有限评论的范围；可回查的来源。

搜索摘要不能当作已读全文。图片“处理完成”不代表每个字都正确。零条评论可能表示该次没有读到，不能直接写成“没有评论”。

## 第六步 按需增加平台

告诉 Agent“继续接通微博和知乎”或“读取这篇公众号文章”。新增平台按需登录，不必为了试用一次全部接通。公众号搜索来自搜狗索引，可能返回旧文章，需要核对原始日期；公众号留言当前不支持。

## 遇到问题时

| 你看到的情况 | 可以直接告诉 Agent |
| --- | --- |
| 下载依赖失败或长时间不动 | 请保留已下载环境，检查网络、代理与失败组件，再从未完成步骤继续；不要关闭证书校验。 |
| 授权后仍未连接 | 我已确认扩展权限，请检查专用浏览器与本地连接，不要重装全部环境。 |
| 显示登录成功却搜不到 | 请实际验证搜索页会话，保留明确错误；不要只用身份检查判断可用。 |
| 页面加载超时 | 请保留失败阶段，检查本次页面状态；不要反复刷新或换账号。 |
| 图片只读到一部分 | 请按原内容记录补读缺失图片，保留已经成功的部分。 |
| 需要验证码或被限流 | 请停止对应平台，保留其他结果；我方便时再正常完成验证。 |
| 当前对话暂时没发现新工具 | 请使用宿主提供的刷新入口；可先用同版 CLI 继续，并说明当前对话是否已经实际调用新工具。不要强杀忙碌服务。 |

不想整理日志，可以使用“试用反馈卡片”，或打开 https://github.com/workstonedai-collab/social-media-read-for-agent/issues/new/choose 。只需描述系统、Agent、想做的任务、做到哪一步；不要上传完整原始日志、账号信息或签名链接。

## 给安装 Agent 的执行参考

这些步骤由 Agent 完成，普通用户不必照抄。完整参数以仓库 installation.md 和 AGENTS.md 为准。

```sh
/bin/bash install.sh --clients codex --install-ocr
# Hermes 用户只配置 --clients hermes
# 只在用户明确需要两边时配置 --clients codex hermes
/bin/bash run.sh setup --open-browser
# 已有专用连接时跳过重复打开和授权
/bin/bash run.sh setup --apply --clients codex --wait-for-browser 180 --open-login xiaohongshu
# 本人完成登录并明确告知后：
/bin/bash run.sh setup --login-completed xiaohongshu --verify --platforms xiaohongshu
```

最后还要用当前 Agent 的 list_platforms、search、get_task、read_content 做真实验收；只有命令行通过不能冒称当前对话已经接通。

## 教程和实测的范围

本教程覆盖首次安装、扩展授权、平台登录、首个任务和故障恢复的全部步骤。安装、扩展授权、平台登录与真实读取需分别验收。本页说明完整操作顺序，不承诺任意网络、系统或账号都一次通过；阅读演示使用已有专用账号，不等同于新机器首次登录验收。网络下载失败时保留已完成步骤，由 Agent 检查下载连接后继续，不需要用户反复重装全部环境。
