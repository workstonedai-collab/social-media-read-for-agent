# 项目定位与新手体验改进

比较日期：2026-10-15。以下比较的是各项目公开 README 的介绍和上手设计，不是对它们的稳定性排名，也不表示其所有宣传都经过本项目验证。未复制这些项目的介绍文案、图片或界面。

## 同类项目中可借鉴的表达

| 参考 | 公开介绍的做法 | 本项目落实方式 |
| --- | --- | --- |
| [Agent Reach](https://github.com/Panniantong/Agent-Reach) | 先举 Agent 无法读取平台的具体场景，再给一句话安装入口、能力表和诊断入口 | 首页先说明产品调研、反馈核对和链接阅读；提供直接交给 Agent 的安装提示；显示确定的平台条数和失败原因 |
| [OpenCLI](https://github.com/jackwener/OpenCLI) | 一句话解释价值，区分普通用户、Agent 和扩展开发者；快速开始分成安装、扩展、检查、首次调用 | 普通用户只看“交给 Agent → 授权 → 登录 → 提问”；开发者和 Agent 的指令放在后续及独立安装文档 |
| [xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp) | 按登录、搜索、详情等具体功能展示操作演示，并保留完整教程 | 增加可重现的四平台搜索阅读演示、真实验收回执和清晰能力表；不把虚构演示包装成真实账号录像 |
| [X-MCP](https://github.com/xpzouying/x-mcp) | 明确面向非技术用户，突出减少部署与可见、可干预的浏览器操作 | 引导使用专用浏览器、正常页面登录；Agent 自动处理配置，用户只参与必要授权；不照搬“无风险”等保证 |

本项目首屏表述：**把账号登录好，其余交给 Agent：跨平台搜索、读原文和图片、查评论，留下可回查的来源。**

GitHub About 使用简短中英文介绍与真实平台关键词；中文 README 使用用户提供的完整介绍，保留预览状态和使用边界。正式技术标识仍是 social-media-read-for-agent。

## 集成之后的具体增量

这些是本项目围绕调研流程所做的增加，不主张行业首创：

- 一个任务结构贯穿四个平台：搜索、正文、评论、逐图 OCR、来源和失败都能回查。
- 缺图补读：逐图检查点保留成功资料，只处理缺失图片，明确记录本次新处理与复用数量。
- 真实验收：登录状态、浏览器连接、真实搜索、取得正文分别记录；安装检查不冒充可用证明。
- 连接更新：兼容业务代码在空闲请求边界加载，保留任务；工具结构和宿主首次发现仍有刷新边界。
- 按需上手：可先接通一个平台；验收只覆盖所选平台，不要求用户一次登录全部账号。
- 失败可解释：普通加载超时、验证要求、索引变化、图片缺失分别返回，保留其他平台成果。

## 本轮已落实的降低门槛措施

1. 中英文 README 与安装文档，普通用户的操作提示在技术配置之前。
2. 无账号、无密钥、无网络、无第三方 Python 包的虚构演示；同一脚本输出可重现，由 CI 比对。
3. `--verify --platforms ...` 支持按需验收；刷新正文，避免用旧缓存证明现在可读。
4. `setup_progress` 分开报告依赖、专用浏览器、客户端配置和真实读取；由 Agent 翻译成用户的下一步。
5. `llms.txt` 指向 Agent 操作说明和安装入口，避免 Agent 在多个文档中猜测。
6. 新页先确认实际导航，再用短同步探测替代页面内长等待；公众号失败包含阶段，评论未加载不报为“成功零条”。

## 后续值得做，但尚未交付

| 优先级 | 改进 | 验收标准 |
| --- | --- | --- |
| 高 | 安装可视化进度与一键恢复入口 | 用户只看到当前待做动作；已有配置/登录不重复操作，错误可继续 |
| 高 | 扩大跨主题、跨日期真实读取样本 | 分开报告搜索、正文、图片和评论成功情况，保留首次失败和恢复记录 |
| 中 | 少依赖的桌面安装包或受支持的上游桌面运行时 | 在干净机器上减少 Python/Node 准备步骤，同时保留专用资料与授权流程 |
| 中 | 用户授权的已打开页面阅读 | 绑定明确选定的专用页面，读当前正文，避免临时文章链接重复解析；不采用日常未授权窗口 |
| 中 | 调研导出与来源归类 | 统一输出来源、日期、用户反馈/品牌稿/教程、未读内容，降低 Agent 误报覆盖的概率 |
| 后续 | 接入更多平台 | 每个平台先验收搜索和阅读，再考虑其他动作，不以平台数量代替实际可用性 |

桌面安装包、自动适配所有 Agent、更多平台、发布与运营并没有在本轮完成。扩展授权与平台验证不能自动跳过；依赖安装和账号相关操作仍遵守宿主授权。
